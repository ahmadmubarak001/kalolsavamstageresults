Publishing help

Put Kalolsavam Live online in about 10 minutes, free of cost

← Back to the live board

Before you publish

  1. Keep all files in one folder: index.html, app.js, style.css, config.js, admin.html, publish-help.html. No build step is needed.
  2. Create your admin account. In Supabase: Authentication → Users → Add user. Then in the SQL editor run: 
    insert into public.admin_users (user_id)
select id from auth.users where email = 'YOUR_EMAIL';
  3. Turn off public sign-ups (recommended): Authentication → Sign In / Providers → disable "Allow new users to sign up". Admins are added by you only.
  4. Test locally: open a terminal in the folder, run npx serve ., and open the address it shows.
Opening index.html by double-click can fail in some browsers. Use npx serve . or one of the hosts below.

Pick a host (all free)

Easiest: Netlify Drop (no account setup, drag and drop)
  1. Go to app.netlify.com/drop and sign in.
  2. Drag your whole folder onto the page.
  3. You get a link like https://random-name.netlify.app. Rename it in Site configuration → Change site name, for example kalolsavam-school.netlify.app.
  4. To update later, drag the folder onto Deploys again.
Cloudflare Pages
  1. Open dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets.
  2. Name the project, upload the folder, and click Deploy.
  3. Your site opens at https://project-name.pages.dev.
GitHub Pages
  1. Create a new public repository on GitHub and upload all the files (Add file → Upload files).
  2. Open Settings → Pages, choose Deploy from a branch, select main and / (root), then Save.
  3. After a minute, your site is at https://USERNAME.github.io/REPO/.
Vercel
  1. Sign in at vercel.com, choose Add New → Project and import your GitHub repository.
  2. Framework preset: Other. Leave the build command empty and click Deploy.

After it is live

  • Open your site. The badge at the top right should say Live. If it says Offline, check your internet and that config.js is uploaded.
  • Open the same site on your phone, then on the admin laptop. Sign in with Admin in the footer (or add #admin to the address). Press Start on a program and watch the phone update without refreshing.
  • Press Results on a program, enter winners, and publish. Everyone sees the result and a small celebration.
  • Rename Venue 1–4 under Manage → Venues.
  • Print a QR code of your site link (any free QR generator) and put it on the notice board.

Optional: custom domain

Every host above has a Domains or Custom domain setting. Add your domain, then create the DNS record the host shows. HTTPS is automatic.

Troubleshooting

  • Blank board / "Could not load data": config.js is missing or the Supabase project is paused. Check the project is active in Supabase.
  • Sign-in says "Invalid login credentials": the user does not exist or the password is wrong. Reset it in Authentication → Users.
  • Signed in but no admin buttons: the account is not in admin_users. The page shows your user id; run the SQL above.
  • Changes save but others do not see them live: check Database → Replication that the Kalolsavam tables are in supabase_realtime (already set up by the migration).
  • Old version still showing: hard-refresh (Ctrl+Shift+R, or clear the site's cache on mobile).

Safe to share

config.js contains only the public key. It is meant to be seen by everyone. Never put a service_role key in these files.
